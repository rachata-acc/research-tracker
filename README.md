# DrRachata AR: Research Tracker

ระบบติดตามเส้นทางการทำวิจัยทางการบัญชี 16 สัปดาห์ สำหรับรายวิชา AC80403 วิทยาระเบียบวิธีวิจัยทางการบัญชี
สาขาวิชาการบัญชี คณะวิทยาการจัดการ มหาวิทยาลัยราชภัฏอุดรธานี

## สำหรับนักศึกษา

1. เปิดลิงก์ของแอปด้วย Chrome, Edge หรือ Safari
2. กด **ติดตั้งแอปลงเครื่อง** บนหน้าปก (iPhone/iPad: กด แชร์ → เพิ่มไปยังหน้าจอโฮม)
3. กรอกข้อมูลนักศึกษา แล้วทำงานตามขั้นตอนใน Timeline

ข้อมูลความก้าวหน้าเก็บอยู่ในเครื่องของนักศึกษาเท่านั้น ไม่มีการส่งไปยังเซิร์ฟเวอร์ใด
ให้กด **ส่งงาน / สำรองข้อมูล → ส่งออกไฟล์ความก้าวหน้า** แล้วส่งไฟล์ .json ให้อาจารย์ตามรอบที่กำหนด
